# App Specification

Build a personal task manager with the following exact feature set:

- Add a task with a title
- Mark a task as complete
- Filter tasks by status: All / Active / Completed
- Clean, usable UI — simple and not complex

The repository should include two versions of the same app:

- `/vibe-version` — generated in one shot as if exported from a vibe coding tool
- `/pair-version` — built file-by-file with an AI pair programming assistant style

Each version must run without errors and expose the same feature set.
